# 本機展示啟動與驗收

展示網址：[http://127.0.0.1:3000](http://127.0.0.1:3000)，本專案 API：[http://127.0.0.1:8001/docs](http://127.0.0.1:8001/docs)。本次使用 8001 避開本機已佔用的 8000；未停止佔用該埠的其他服務。

## 重新啟動（Windows PowerShell）

目前服務已啟動；以下命令供重開機或終止服務後使用。若連接埠已被本專案使用，不必再次啟動。

終端一，在專案根目錄啟動持久化資料服務：

```powershell
docker compose up -d database qdrant
cd backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8001
```

終端二，在專案根目錄：

```powershell
cd frontend
$env:NEXT_PUBLIC_API_BASE_URL = 'http://127.0.0.1:8001'
npm run build
npm run start -- --hostname 127.0.0.1
```

上述命令使用已安裝的 Python／Node 依賴、現有 Docker 資料卷，以及本機 `backend/.env`。新電腦需先依 README 安裝、migration、匯入並同步向量。瀏覽器 API 位址在 build 時寫入前端，換埠後須重建。
